학교 안의 작은 문제를 AI로 탐구하다

학교생활을 하다 보면 쉬는 시간이나 하교 직전에 창밖 날씨가 궁금해지는 순간이 많습니다. 우리는 복도 끝이나 교실 바깥으로 직접 나가지 않고도 창가의 상황을 인공지능으로 미리 파악할 수 있는 방안을 고민하게 되었습니다.

이 프로젝트는 고등학생들의 일상 속 소소한 궁금증과 불편을 해소하기 위해 시작되었습니다. 창가 풍경 이미지를 인공지능에 학습시켜, 학생들이 실시간으로 날씨 상태를 확인할 수 있는 간결하고 유용한 웹 체험 공간을 제공합니다.

해결하려는 문제

수업이 끝나거나 다음 교시를 준비할 때, 밖에 비가 내리고 있는지 확인하기 위해 매번 멀리 떨어진 창문이나 복도로 이동하는 것은 다소 번거로운 일입니다. 특히 이동 수업이나 급식실 이동 전 날씨를 미리 파악하지 못해 당황하는 경우가 자주 발생하곤 합니다.

우리는 이러한 문제를 해결하기 위해 창밖을 향한 카메라 입력만으로 현재 날씨 상태를 분류해 내는 인공지능 탐구 모델을 기획했습니다.

주요 사용자

본 웹 서비스의 핵심 사용자는 교실 안에서 빽빽한 일정을 보내는 고등학생들입니다. 쉬는 시간이나 점심시간, 그리고 하교 직전 교실을 나서기 전 빠르게 날씨 변화를 파악하고자 하는 학생들에게 가장 최적화되어 있습니다.

스마트폰을 이용해 언제 어디서나 손쉽게 접속하여 직관적인 분석 결과를 얻을 수 있도록 사용자 환경을 구성하였습니다.

모델이 구분하는 클래스

저희가 구축한 티처블 머신 이미지 분류 모델은 창밖 풍경 데이터를 학습하여 현재 상태를 정확히 두 가지 클래스로 구분합니다.

분류 기준이 되는 실제 클래스는 비와 맑음입니다. 실시간으로 입력되는 카메라 영상 분석을 거쳐 각 클래스에 해당할 확률을 백분율로 계산해냅니다.

'카메라 시작' 버튼을 누르면 실시간 창밖 날씨 분석이 시작됩니다.

모델의 한계와 사람의 역할

인공지능 모델이 모든 상황을 완벽하게 판별하는 것은 아닙니다. 데이터 수집 환경의 특성상 현재 모델은 맑음으로 판단하는 경향이 상대적으로 더 높게 나타나는 한계점을 가지고 있습니다.

따라서 화면에 나타나는 인공지능의 예측 결과만을 과신하기보다는, 보다 확실한 판단을 위해 창밖에서 빗소리가 나고 있지는 않은지 직접 귀로 소리를 들어 확인해보는 교차 검증 과정이 반드시 필요합니다.

탐구 팀 소개
